## Target boundary

The [platform contract](../target/platform-app-contract.md) proposes DBX-native event/process identities, multiple code values, and typed manual outputs in a controlled submission envelope. It is not the Airtable schema copied verbatim. Removing runtime reliance on Airtable requires DBX-owned catalogs and approved key/representation mappings; retaining Airtable identifiers here as baseline provenance does not satisfy or prevent that future work.
